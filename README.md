# faster-chant-300-hero-rust

《300高速咏唱装置》Rust 重构版。

基于 [Anran-233/FasterChantDevice](https://github.com/Anran-233/FasterChantDevice) 用 Rust 重写，保留原有功能逻辑，优化架构设计。

## 功能

- 全局键盘钩子，游戏内一键呼出悬浮面板
- 99 个预设方案，最多 90 条快捷发言
- 拼音首字母 / 编号双模式搜索切换方案
- 连发模式，自定义间隔自动发送
- 游戏模式 / 聊天模式双模式切换
- 自定义面板样式（颜色、描边、字体）
- 系统托盘常驻

## 技术栈

- Rust
- windows-rs（Win32 API）
- tiny-skia（文字渲染）
- egui / winit（GUI）
